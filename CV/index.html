Proyectos

Proyecto Final de Estructura de Datos: "Taller de Autos"

Este proyecto consistió en el desarrollo de un sistema de escritorio para la gestión de un taller automotriz, utilizando una interfaz gráfica en Java y estructuras de datos dinámicas personalizadas.

Se implementó una solución donde la interfaz de usuario se construyó con la biblioteca Swing de Java, permitiendo el registro y consulta de clientes, vehículos, trabajos y facturación. La gestión de los datos en memoria se realizó mediante listas enlazadas simples (ListaClientes, ListaVehiculos, ListaTrabajos y ListaFacturas) con nodos personalizados, evitando el uso de colecciones predefinidas para manipular la información de forma secuencial. Adicionalmente, el sistema incorporó la persistencia de datos en archivos locales mediante Java I/O (FileWriter / PrintWriter) para generar e imprimir automáticamente las facturas y comprobantes de pago en archivos de texto (.txt).

Proyecto I de Programación IV: Sistema de Ventas y Distribución "Nova Online".

Este sistema integrado se estructuró en varios componentes conectados mediante sockets, utilizando un Simulador con interfaz gráfica en C# para enviar tramas de datos. El Verificador se desarrolló en el lenguaje Python utilizando un motor de bases de datos MySQL, aplicando cifrado AES para datos sensibles y gestionando bitácoras en segundo plano mediante hilos. Por su parte, el componente de Almacén se programó en Java utilizando procedimientos almacenados en una base de datos SQL Server, e implementando triggers para automatizar el control y la actualización del inventario.
